04 Nginx, puertos, SSL y dominio

Nginx corre en el host de 172.16.3.21 (no en Docker). Next.js solo en 127.0.0.1:3000; API en 172.16.3.22:4000.

Puertos y firewall

PuertoUso
80HTTP → redirige a HTTPS
443HTTPS interno y portal público
3000Solo localhost (Next.js)
4000Backend en .22 (proxy desde Nginx)
 
sudo ufw status
sudo ss -tlnp | grep -E ':80|:443|:3000'

Archivos y SSL

Archivo / rutaContenido
/etc/nginx/conf.d/muni-union-upstreams.confUpstreams, body size, timeouts
/etc/nginx/sites-available/muni-unionBloques server
/etc/nginx/ssl/internal/Certificado sistema IP 172.16.3.21
/etc/nginx/ssl/public/Certificado portal verificar.muniunion.gob.pe

Carga masiva (valores reales de producción)

client_max_body_size 500M;
client_body_timeout 300s;
proxy_connect_timeout 15s;
proxy_send_timeout 360s;
proxy_read_timeout 360s;
send_timeout 360s;

Frontend espera hasta 10 minutos (timeout: 600000). Tras editar Nginx: sudo nginx -t && sudo systemctl reload nginx.

Proxy API y documentos

location /api/     { proxy_pass http://backend; }
location /uploads/ { proxy_pass http://backend; }

Sin /uploads/ no se pueden ver las actas digitalizadas desde la interfaz.

Dominio / Configuración (por defecto = IP)

Menú admin → Configuración. Valor por defecto: https://172.16.3.21 (migración 006 y fallback del Backend). Se imprime en constancias. No actualiza sola Nginx/DNS.

  1. DNS del dominio → 172.16.3.21.
  2. Editar server_name público en sites-available/muni-union.
  3. Certificado en /etc/nginx/ssl/public/.
  4. sudo nginx -t && sudo systemctl reload nginx
  5. Guardar la misma URL en Configuración.
GET /api/configuracion
PUT /api/configuracion/url-verificacion
{ "url_verificacion_publica": "https://172.16.3.21" }

psql -U app_user -h 172.16.3.23 -d registro_muni_union \
  -f /opt/muni_union/back/src/migrations/006_configuracion_sistema.sql

07 Backups (varias formas)

A) Desde la aplicación

Login admin → Backup BD → Descargar .sql. Usa DB_HOST=172.16.3.23 del Backend.

B) Desde VM PostgreSQL .23

ssh deploy@172.16.3.23

sudo -u postgres pg_dump -Fc registro_muni_union \
  > /mnt/backups/manual_$(date +%F_%H%M).dump

sudo -u postgres pg_dump -Fp --no-owner --no-acl registro_muni_union \
  > /mnt/backups/manual_$(date +%F_%H%M).sql

ls -lh /mnt/backups/

C) Restaurar

sudo -u postgres pg_restore -d registro_muni_union --clean --if-exists \
  /mnt/backups/manual_YYYY-MM-DD_HHMM.dump

sudo -u postgres psql -d registro_muni_union \
  -f /mnt/backups/manual_YYYY-MM-DD_HHMM.sql

10 Importación, filtros y API

Importación: POST /api/importacion, 30.000 filas, 500 MB, timeout frontend 10 min, Nginx proxy 15 min (ver sección 04).

Filtros actas: código exacto, folio exacto, libro exacto; exportación usa los mismos filtros.

API clave: /api/backup/download, /api/configuracion, /api/verificar/solicitud/:id.
