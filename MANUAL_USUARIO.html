01 A quién va dirigido y qué es el sistema

Este manual es para el personal que usa el sistema a diario y para quien administra las cuentas dentro de la municipalidad. No hace falta ser programador.

El Sistema de Registro Civil es una aplicación web (se abre en el navegador) para actas, personas, digitalización, trámites y verificación de constancias.

Acceso de producción (red municipal):

03 Inicio de sesión

  1. Abra el navegador e ingrese https://172.16.3.21.
  2. Escriba usuario y contraseña.
  3. Pulse Ingresar. Verá el Dashboard (tablero de resumen).

Cerrar sesión: ícono de usuario (arriba a la derecha) → Cerrar sesión.

04 Dashboard

Pantalla de resumen: cantidades de actas, ciudadanos, solicitudes y gráficos. No se registran actas aquí; solo se consulta el estado general.

05 Actas

Menú → Actas. Una acta es el registro oficial (nacimiento, matrimonio o defunción).

Filtros (también valen para exportar a Excel)

CampoCómo usarlo
Código o folioNAC-L1-1 busca exacto; solo 1 busca el folio 1 (no el 10 ni el 100)
Libro2 o L2 exacto
DNI / nombres / año / tipo / fechasSe combinan con los anteriores

Registrar

  1. Nueva Acta → tipo → Libro clásico o CUI.
  2. Titular (y cónyuge en matrimonio).
  3. Fecha del acta → Guardar.

Anular pide motivo obligatorio. Reactivar: solo administrador.

06 Digitalización

Menú → Digitalización. Sube el PDF o imagen del acta física (PDF/JPG/PNG, máx. 20 MB). Si ya había archivo, el nuevo lo reemplaza.

07 Personas

Busque antes de crear. Para recién nacidos use Sin documento. Si hay coincidencia dudosa sin DNI, revise el acta física antes de asumir que es la misma persona.

08 Solicitudes

  1. Nueva Solicitud → solicitante → actas → guardar (PENDIENTE).
  2. Atender cuando el ciudadano recoja el documento.
  3. Imprimir Constancia: al pie va el enlace de verificación.

09 Verificación pública

El ciudadano no necesita usuario. Dirección por defecto en producción:

https://172.16.3.21/verificar
https://172.16.3.21/verificar/000001

El administrador define qué URL se imprime en constancias nuevas (menú Configuración). Por defecto es la IP.

10 Importación, backup y configuración Admin

Importación masiva

Excel .xlsx/.xls + ZIP opcional. Hasta 30.000 filas y 500 MB. Puede tardar hasta 10 minutos. Resultados: OK, OMITIDO, OMITIDO_DOC, ERROR. No reintente de inmediato si hay espera larga.

Backup

Menú → Backup BD → descargar .sql y guardarlo en lugar seguro. El técnico también puede respaldar desde el servidor de base de datos (ver Manual Técnico).

Configuración (URL de verificación)

  • Por defecto: https://172.16.3.21
  • Dominio futuro (ejemplo): https://verificar.muniunion.gob.pe
Guardar la URL en el sistema no configura sola internet ni Nginx. Si usarán un dominio nuevo, el técnico debe preparar DNS, certificado y Nginx.

11 Usuarios, auditoría y FAQ

Usuarios: crear operadores, permisos, activar/desactivar. Admin inicial aespinoza / 123456.

Auditoría: historial de quién hizo qué, cuándo y desde qué IP.

¿No carga el sistema? Verifique red municipal y la dirección exacta. Si sigue fallando, avise a sistemas.

¿Importación con error inesperado? Espere y revise si las actas ya están; no recargue el mismo lote de inmediato.
