01 Introducción y acceso

El Sistema de Registro Civil permite registrar, consultar y digitalizar actas de nacimiento, matrimonio y defunción, y atender solicitudes de copias certificadas.

Acceso de producción:
https://172.16.3.21
CampoValor inicial
Usuario administradoraespinoza
Contraseña123456 (cambiar al primer ingreso)

Los demás usuarios se crean después desde el módulo Usuarios.

02 Roles

RolAccesos
AdministradorAcceso total: usuarios, auditoría, backup, configuración, importación y operación
OperadorDigitalización, personas, actas y solicitudes según permisos

03 Inicio de sesión

  1. Abrir el navegador e ingresar https://172.16.3.21.
  2. Ingresar usuario y contraseña.
  3. Clic en Ingresar.

Cerrar sesión: ícono de usuario (arriba a la derecha) → Cerrar sesión.

04 Dashboard

Muestra resúmenes de actas, ciudadanos, solicitudes y gráficos de evolución mensual.

05 Actas

Menú → Actas. La exportación Excel usa los mismos filtros visibles.

FiltroComportamiento
Código o folioNAC-L1-1 exacto; solo 1 = folio exacto
Libro2 o L2 exacto
DNI / nombres / año / tipo / fechasCombinables con los anteriores

Registrar

  1. Clic en Nueva Acta.
  2. Seleccionar tipo y modo Libro Clásico o CUI.
  3. Completar titular (y cónyuge en matrimonio).
  4. Ingresar fecha del acta y guardar.

Anular

Menú ⋮ → Anular → motivo obligatorio. Reactivar: solo Administrador.

06 Digitalización

Menú → Digitalización. Adjuntar PDF/JPG/PNG (máx. 20 MB). Si ya había documento, el nuevo lo reemplaza.

07 Personas

Buscar antes de crear. Para recién nacidos usar Sin documento. Si hay coincidencia dudosa sin DNI, revisar el acta física.

08 Solicitudes

  1. Nueva Solicitud → buscar solicitante → agregar actas → guardar (PENDIENTE).
  2. Atender cuando el ciudadano recoge el documento.
  3. Imprimir Constancia: al pie aparece la URL de verificación.

09 Verificación de constancias

Sin login. Producción actual por IP (valor por defecto del sistema):

https://172.16.3.21/verificar
https://172.16.3.21/verificar/000001

La URL base por defecto es https://172.16.3.21 (menú Configuración). Si más adelante hay dominio público, el administrador la cambia; las nuevas constancias usarán esa URL.

10 Importación masiva Admin

Excel .xlsx/.xls + ZIP opcional. El servidor admite hasta 500 MB por archivo y tiempos largos de proxy. Resultados: OK, OMITIDO, OMITIDO_DOC, ERROR. Esperar hasta 10 minutos; no reintentar de inmediato si hay timeout.

11 Backup Admin

Menú → Backup BD → Descargar. Guardar el .sql en medio seguro. El administrador técnico también puede respaldar desde la VM PostgreSQL 172.16.3.23 (ver Manual Técnico).

12 Configuración (dominio/IP) Admin

Menú → Configuración. La URL base impresa en constancias:

  • Por defecto (producción): https://172.16.3.21
  • Futuro dominio (ejemplo): https://verificar.muniunion.gob.pe
Cambiar la URL en el sistema no configura sola el DNS ni Nginx. Si usa un dominio nuevo, el área técnica debe actualizar Nginx, puertos 80/443 y certificados en 172.16.3.21 (ver Manual Técnico).

13 Usuarios y auditoría Admin

Usuarios: crear operadores, asignar permisos, activar/desactivar.

Auditoría: quién hizo qué, sobre qué registro, IP y fecha. Se puede exportar.

Cambiar contraseña desde el menú de usuario (esquina superior derecha).

14 Preguntas frecuentes

¿Cómo imprimo este manual? Abrir este HTML y usar Ctrl+P → Guardar como PDF o Imprimir.

¿Dónde verifica el ciudadano? https://172.16.3.21/verificar o la URL impresa en la constancia.

¿Qué hago si la importación falla por tiempo? No reintentar de inmediato; verificar si las actas ya se registraron.
