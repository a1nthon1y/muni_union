# Capturas del Manual de Usuario

Coloque aquí las capturas en formato PNG. `MANUAL_USUARIO.html` las carga automáticamente por nombre.

## Reglas

- Nombre: `figura-X-Y.png`, en minúsculas.
- Ancho recomendado: entre 1366 y 1920 píxeles.
- Oculte contraseñas, credenciales y datos personales innecesarios.
- Use datos de prueba autorizados para errores, anulaciones y fusiones de duplicados.
- No recorte los títulos, botones o mensajes necesarios para comprender el paso.
